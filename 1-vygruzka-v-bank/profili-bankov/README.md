# Профили банков

Ядро генератора одно, различия между банками — здесь. Профиль указывается
у плательщика полем `bank_profile` или флагом `--profile`.

| Параметр | Что решает |
|---|---|
| `format_version` | `1.02` (принимают почти все) или `1.03` |
| `encoding` | `Windows` → cp1251, `DOS` → cp866 |
| `sender` / `receiver` | что писать в шапке файла |
| `emit_empty_fields` | выводить пустые необязательные строки или опускать |
| `uin_when_absent` | что писать в `Код` (УИН), когда его нет: `0` или пусто |
| `purpose_max_length` | обрезка назначения платежа, по умолчанию 210 |
| `payment_kind` | `ВидПлатежа`: пусто = электронно |
| `payment_type` | `ВидОплаты`, для платёжки `01` |
| `priority` | `Очередность`, обычно `5` |
| `duplicate_purpose_line` | дублировать назначение в `НазначениеПлатежа1` |
| `income_code_for_persons` | `КодНазПлатежа` (поле 20) при выплате физлицу и самозанятому: `1` по умолчанию, пусто — не ставить |

Новый банк = копия `default.json` с изменённым `name` и правками под его придирки.
Придирки выясняются пробной загрузкой — чек-лист в FORMAT-1CClientBankExchange.md, п. 8.
